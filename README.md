# 🛡 Cyber Crime Complaint Management System

A modern and responsive Cyber Crime Complaint Management System built using HTML, CSS, and JavaScript.

This project helps users:
- Register and Login
- File Cyber Crime Complaints
- Upload Evidence
- Track Complaint Status
- Manage User Profiles
- View Complaint Details
